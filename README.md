# dexc 🌐

Uno script leggero e veloce scritto in **Bash** per eseguire la scansione della rete locale e diagnosticare i dispositivi connessi.

## 🛠 Funzionalità
* Rilevazione automatica dell'interfaccia di rete attiva.
* Identificazione della subnet locale.
* Scansione rapida dei dispositivi sulla rete tramite `nmap`.

## 📦 Requisiti
Lo script richiede `nmap` installato sul sistema:

* **Arch Linux / EndeavourOS:** `sudo pacman -S nmap`
* **Fedora:** `sudo dnf install nmap`
* **Debian / Ubuntu:** `sudo apt install nmap`
